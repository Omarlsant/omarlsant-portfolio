# Omar Lengua — Portfolio Profesional 🚀

Bienvenido/a a mi portfolio profesional. Aquí encontrarás una selección de mis proyectos y trayectoria enfocados en desarrollo backend, ingeniería de datos e inteligencia artificial.

## 🛠️ Tecnologías y Herramientas

- **Frontend & Core**: React 19, TypeScript, Vite
- **Estilos**: Tailwind CSS v4
- **Navegación**: React Router DOM (BrowserRouter)
- **Componentes & UI**: Swiper, React Icons
- **Despliegue**: GitHub Pages con GitHub Actions CI/CD

## 🚀 Instalación y Desarrollo Local

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar bundle de producción
npm run build
```
